# DMS 本地浏览器仪表盘

## 基本信息

- **修改日期** 2026-11-16（北京时间）
- **模块** DMS 主程序与实时监测界面
- **涉及文件** `fatigue_detection/src/main.py`、`src/detector.py`、`src/web_dashboard.py`、`dashboard/`、`tests/test_web_dashboard.py`、启动器与运行说明

## 改动与改善

- 将摄像头画面、疲劳等级、EAR/MAR、PERCLOS、连续闭眼、头姿、眨眼和分数趋势分区展示。人脸与眼部观测状态独立显示，缺失值显示为破折号。
- 原有检测线程向本机浏览器提供 JPEG 画面与遥测。支持关键点开关、摄像头截图、评分重置、停止监测，以及本地已加载模型时的分心开关。浏览器采用视觉等级提示，便于静音录屏。
- 新增浏览器启动器与 `--web` 入口。默认摄像头打不开时尝试设备 0。配置模型路径缺失时可加载仓库内随附模型，保留 OpenCV 启动入口。

## 验证结果

- 14 项现有核心测试、9 项观测回放和 3 项新仪表盘接口测试通过。另实测内置摄像头设备 0 的 640×480 画面、JPEG 截图、关键点开关、评分重置及停止状态。
- 浏览器用受控视频与遥测验证画面渲染、关键点开关、分心开关。390、768、1024 像素宽度下，页面无横向溢出或面板重叠。验证了默认模型路径缺失时加载随附模型。
- **验证范围** 本机摄像头数据链路和模拟浏览器显示。服务仅监听本机地址。共享仓库当前基线不含本地分心模型，分心能力按运行环境显示。
