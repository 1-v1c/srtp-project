# DMS 张嘴场景的头姿与眼部有效性修复

## 基本信息

- **修改日期** 2026-11-16（北京时间）
- **模块** DMS 头姿估计、眼部观测状态提示和 CalibTool 桌面端共用头姿实现
- **涉及文件** `fatigue_detection/src/features.py`、工具包桌面版 `features.py`、`dashboard/dashboard.js`、`tests/test_upper_face_pose.py`、运行说明与参考数据许可

## 改动与改善

- 运行日志中存在张嘴时人脸有效、偏航越过 25°、眼部无效的样本。复算既有截图发现旧求解可接受位于相机后方的解，横滚会接近 180°。
- 使用 MediaPipe 标准模型中的 10 个上半脸参考点求头姿，排除张嘴时移动的嘴角和下巴。拒绝负深度和重投影误差过大的姿态，保留 25° 侧脸门控。
- 网页将眼部无效原因显示为未定位人脸、头姿估计不可用或侧脸保护，便于区分信号缺失与门控。

## 验证结果

- 14 项核心测试与 23 项观测、接口及姿态回归通过。新增 5 项覆盖正脸张嘴、35° 侧脸、低头角度符号、负深度和高重投影误差。
- 本地正面与侧面截图复算分别通过与触发眼部门控。正面截图上模拟只移动嘴部和下巴，MAR 从 0.41 增加到 1.30，偏航与 EAR 保持一致。侧面截图复算偏航约 40.6°，继续排除眼部信号。
- **验证范围** 已有日志与截图、合成关键点和离线回归。最新现场张嘴视频仍待重新录制核对。
