# DMS 浏览器会话暂停与继续

## 基本信息

- **修改日期** 2026-11-16（北京时间）
- **模块** DMS 浏览器仪表盘、摄像头采集与日志
- **涉及文件** `fatigue_detection/src/main.py`、`src/web_dashboard.py`、`dashboard/`、`tests/test_web_dashboard.py` 和运行说明

## 改动与改善

- 将结束采集的页面按钮改为「暂停监测／继续监测」。暂停时释放摄像头、停止写入 CSV，网页继续运行。恢复时重新打开摄像头，并追加到同一份 CSV。
- 暂停区间中断连续闭眼等时间状态，恢复后重新累计。历史评分曲线保留可见记录，恢复后的点与暂停前的曲线断开。若摄像头暂时无法打开，可在页面重试。

## 验证结果

- 14 项核心测试与 13 项观测和接口测试通过。用内置摄像头完成两轮暂停与恢复，暂停时 CSV 行数保持不变，继续后同一文件立即追加新行。浏览器点击验证了状态、画面和按钮双向切换。
- **验证范围** 本机浏览器和内置摄像头。现有旧进程需要重新启动一次以加载新版本。
