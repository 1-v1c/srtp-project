# AEB 驾驶员制动命令行参数

## 基本信息

- **修改日期** 2026-11-18（北京时间）
- **模块** AEB 纵向软件在环
- **涉及文件** 单工况入口、共享场景与车辆循环、入口测试、aeb/README.md

## 改动与改善

- 单工况入口新增 `--driver-brake-mps2`、`--driver-brake-start-s`、`--driver-brake-end-s`。驾驶员制动请求填正值，默认强度为零，开始/结束默认为 0/30 秒。
- 在每个 20 ms 控制周期先采样驾驶员请求，写入数据盒后调用所选 AEB 策略。V3 使用制动较大值的现有仲裁逻辑，最终指令通过共同的车辆执行器模型。
- 汇总 CSV 保存参数，轨迹 CSV 添加 `driver_request_mps2`，曲线第一行按负加速度绘制驾驶员请求与仲裁后指令。区间左闭右开，CSV 按最近控制周期的采样请求对齐。

## 验证结果

- 25 项测试通过。新增检查正值驾驶员制动被车辆执行、非对齐边界按控制周期采样、充分人工制动、错误区间和非法值。
- 默认 60/40 km/h、22 m 前车减速工况中，驾驶员在 2–6 s 请求 2 m/s²，V3 L0 无接触，最小净距 3.802 m。输出 6001 行轨迹、1 行汇总及四行曲线。
- 驾驶员默认零输入时，原批量仿真两份 CSV 和曲线图的 SHA-256 与已有结果一致。
- **验证范围** 正值驾驶员减速度请求及既有执行器，驾驶员输入为预定的恒定幅值时间段。
