# AEB 驾驶员加速与减速仿真

## 基本信息

- **修改日期** 2026-11-18（北京时间）
- **模块** AEB 单工况仿真及共享车辆模型
- **涉及文件** `aeb/simulate_staged_brake.py`、`aeb/simulate_single_case.py`、`aeb/tests/test_simulate_single_case.py`、`aeb/README.md`

## 改动与改善

- 在既有驾驶员制动参数之外，增加 `--driver-accel-mps2`、`--driver-accel-start-s`、`--driver-accel-end-s`，支持同一轮仿真先加速、再减速。两种强度均填非负值，零表示不操作。
- 控制器输入沿用 `a_driver` 正值制动、负值加速的约定；人工加速与制动区间重叠时制动优先。AEB 或驾驶员输出正制动指令时抑制加速，未制动时执行加速请求。
- 仿真车辆执行器接收带符号纵向请求，加速及制动统一经过执行延迟和变化率限制。输入按 20 ms 控制周期采样；车辆每 5 ms 积分。
- 逐帧 CSV 保留原驾驶员制动列，增加原始加速强度及人工重叠仲裁后的纵向请求。四行图第一行对照驾驶员请求和最终指令，纵向量采用加速正、制动负。README 同步更新完整命令和参数表。

## 验证结果

- `python -m unittest discover -s aeb/tests`：29 项测试通过；新增覆盖加速到车辆和 CSV、AEB 抑制加速、人工加速/制动重叠、非法加速参数，两种控制器均覆盖加速和 AEB 覆盖行为。
- 默认批量仿真的汇总 CSV、逐帧 CSV 和 PNG 与原始无人工输入输出逐字节一致。
- 示例使用默认 V3 L0 工况，自车初速 60 km/h、前车初速 40 km/h、净距 22 m；人工加速 1 m/s²（0–1 s）、制动 2 m/s²（2–6 s）。输出 6001 条轨迹，实际加速度覆盖约 +1 至 -8 m/s²，30 s 内未接触，最小净距 2.203 m；已检查四行曲线图。
- **验证范围** 简化纵向点质量车辆及执行器模型；加速输入为期望加速度，未建立发动机、挡位或油门开度模型。尚未进行 CARLA 或实车联调验证。当前每种人工操作配置一个恒定强度时间区间。
