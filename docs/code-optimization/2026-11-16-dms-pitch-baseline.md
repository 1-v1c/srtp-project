# DMS 个人 Pitch 归零与低头评分限幅

## 基本信息

- **修改日期** 2026-11-16（北京时间）
- **模块** DMS 头姿判定、评分器及浏览器界面
- **涉及文件** `fatigue_detection/src/`、CalibTool 桌面运行入口及对应模块、`dashboard/`、`tests/` 和运行说明

## 改动与改善

- 采集连续 3 秒稳定正视观测的 Pitch 中位数，作为当前会话的个人基线。采集中暂停低头加分。换人或调整座椅后可在网页「重新归零」，桌面窗口可按 `c`。暂停和继续沿用已完成的基线。
- 用相对 Pitch 判断低头，并在侧脸或明显歪头时停用该相对读数。网页和运行日志记录原始 Pitch、基线和相对 Pitch。重新标定时清除旧的低头分项。
- 将持续低头贡献封顶为 3 分。单独持续低头最多达到 L1，其他疲劳分项继续参与融合。

## 验证结果

- 14 项既有核心测试和 18 项观测、标定及接口测试通过，桌面工具包核心测试通过。
- S01–S04 的 12 段已有正视录像特征均完成离线基线采集，完成时间约为 3.0–4.7 秒。模拟原始 Pitch 为 +9° 的正视，归零后相对 Pitch 为 0°，低头不加分。
- 持续低头回放封顶 3 分。实验 B 的闭眼场景仍在闭眼开始约 2 秒后达到 L3。通过浏览器验证了重新归零和相对角度的状态更新。
- **验证范围** 既有标定数据离线回放和模拟帧浏览器验证。安装条件、不同身高及座椅位置在目标摄像头上的独立验证待做。
