# AEB 制动接口与触发稳定性优化

## 基本信息

- **修改日期** 2026-11-16（北京时间）
- **模块** AEB 制动策略和数据盒子
- **涉及文件** `brake_algorithm.py`、`data_box.py`、`tests/test_brake_algorithm.py`

## 改动与改善

- 在数据盒子调用中补齐 `dx`、`dy`，使 CARLA 的逐帧调用入口能够计算 TTC 并回写制动结果。
- 按加速和制动的符号区分驾驶员操作。无风险踩油门样例的误制动从 2.00 m/s² 降为 0。有风险时保留 AEB 请求。
- 使用 `target_valid` 清除无效目标或丢失目标遗留的 AEB 输出，并保留主动制动。该字段由上游路径威胁筛选提供。
- 将接近速度增益改为距离和速度的连续过渡。在 30 m 软件回放中，制动等级从 0、1、0、1、0 变为全程 0。对越界疲劳等级给出明确参数错误。

## 验证结果

- 10 项回归测试通过。50 Hz 简化纵向闭环仿真覆盖跟车、静止前车和前车急刹各 4 个疲劳等级，共 12 组未发生碰撞。
- 跟车场景 L3 在 0.20 s 介入，L0 在 1.14 s 介入。前车急刹的 L0 场景比旧版晚 0.18 s 介入，最小间距由 0.84 m 降为 0.68 m。
- **验证范围** Python 回归及纵向闭环仿真。CARLA 中的传感器输入、路径筛选和制动执行待联调。
