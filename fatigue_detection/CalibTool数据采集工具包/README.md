# CalibTool 数据采集工具包

驾驶员疲劳检测 SRTP 项目 — 特征数据采集工具（EAR / MAR / HeadPose 三种标定）。
由 DMS 端成员开发，供数据采集组使用。

---

## 一、工具包结构

```
CalibTool数据采集工具包/
├── 启动CalibTool网页版.bat   ← ★ 推荐：双击启动（浏览器界面，最友好）
├── 启动CalibTool桌面版.bat   ← 备用：双击启动（OpenCV 窗口版）
├── launcher_web.py          ← 网页版启动器（自动定位路径，无需修改）
├── launcher_desktop.py      ← 桌面版启动器
├── requirements.txt         ← Python 依赖清单
├── README.md                ← 本文件
├── 实验流程手册.md           ← ★ 必读：标准实验流程与采集要求
├── models/
│   └── face_landmarker.task ← MediaPipe 人脸模型（两个版本共用，勿删）
├── web/                     ← 网页版（浏览器界面）
│   ├── index.html
│   ├── css / js / vendor    ← 界面与算法代码、MediaPipe 运行库
└── desktop/
    └── src/                 ← 桌面版代码
        ├── calibtool.py     ← 桌面版主程序
        └── config.py ...    ← 配套模块（勿随意修改）
```

## 二、首次使用：环境安装（一次性）

> 需要电脑已安装 **Python 3.10~3.12**（64 位）。没有的话先装：
> https://www.python.org/downloads/ （安装时勾选 "Add to PATH"）

1. 打开 PowerShell / CMD
2. 进入本工具包目录（可拖拽文件夹进终端）
3. 执行安装：

```powershell
python -m pip install -r requirements.txt
```

看到 `Successfully installed` 即完成。

**验证是否装好**（可选）：

```powershell
python -c "import cv2, mediapipe, numpy, PIL; print('OK')"
```

输出 `OK` 即可。

## 三、启动工具

### 方式一：网页版（推荐）

**双击 `启动CalibTool网页版.bat`**，浏览器自动打开，出现界面即成功。

- 首次会请求**摄像头权限**，点"允许"
- 保持黑色终端窗口开启（它是服务器），用完后关闭即可

### 方式二：桌面版（备用）

**双击 `启动CalibTool桌面版.bat`**，出现 OpenCV 窗口即成功。
（若模型加载报错，多为 Python 版本过新/过旧导致 MediaPipe 不兼容）

## 四、界面与操作

网页版界面分为：
- **顶部栏**：EAR / MAR / HEAD 模式切换 + 实时数值（EAR、MAR、Pitch/Yaw/Roll）
- **左侧**：摄像头画面（人脸关键点实时标注）
- **右侧面板**：标签选择、录制控制、实时统计、采集记录、导出

### 核心操作流程（每个状态一段）

```
1. 选择模式（EAR / MAR / HEAD）   ← 顶部按钮 或 按 1/2/3
2. 选择标签（如"正常睁眼"）       ← 点按钮 或 按 Tab/B 切换
3. 坐好，按 空格 开始录制          ← 保持动作 5~10 秒
4. 按 空格 停止                    ← 自动统计 min/max/avg 并存入记录
5. 换下一个标签，重复 1~4
6. 全部录完，点「E · 导出 CSV」    ← 下载数据文件（Excel 可打开）
```

### 快捷键速查

| 按键 | 功能 |
|:---:|:-----|
| `空格` | 开始 / 停止录制 |
| `Tab` / `B` | 下一个 / 上一个标签 |
| `1` `2` `3` | 切换 EAR / MAR / HEAD 模式 |
| `E` | 导出全部记录为 CSV |
| `H` | 帮助面板 |
| 点击记录卡片 | 选中（可查看统计 / 删除） |

### 标签一览（按模式）

| 模式 | 标签 |
|:---:|:-----|
| EAR | 正常睁眼 / 眯眼 / 完全闭眼 / 快速眨眼 / 侧脸睁眼 |
| MAR | 正常闭嘴 / 微笑 / 正常说话 / 张嘴惊讶 / 大笑 / 真打哈欠 |
| HEAD | 正对屏幕 / 低头 / 抬头 / 左转 / 右转 / 左倾 / 右倾 |

### 导出数据说明

CSV 每行一帧，字段：`record, phase, label, time, t, ear_l, ear_r, ear_avg, mar, pitch, yaw, roll`
- 用 Excel 打开自动分列；`record` 相同的一批行 = 同一次录制
- 请按「实验流程手册」的要求统一命名并整理保存

## 五、注意事项（重要）

1. **模型文件勿删勿移**：`models/face_landmarker.task`（约 3.7MB）被两个版本共用，丢失后工具无法运行
2. **网页版必须通过 bat 启动**：直接双击 `index.html` 打不开（浏览器安全限制）；也不要手动关掉黑色终端窗口（关了网页就断了）
3. **摄像头**：录前确认没有其他软件（微信/腾讯会议等）占用摄像头；画面卡顿可把分辨率调低（右侧面板 1280×720 → 640×480）
4. **光线**：正对光源，避免背光/侧强光（会导致脸部关键点丢失）
5. **录制中保持人脸在画面内**：人脸丢失的帧不会记入数据，但丢失过多（>10%）的录制建议重录
6. **时长**：每段录制 **5~10 秒**（见实验手册的具体要求），少于 5 帧的数据会被自动丢弃
7. **Pitch 偏移**：网页版右侧「Pitch 偏移」用于校准摄像头摆放角度——先录 10 秒"正对屏幕"，把平均 Pitch 填入，之后低头报警才准
8. **桌面版模型路径**：若提示模型找不到，说明 MediaPipe 无法读取中文路径，请改用网页版
9. **数据导出后及时整理**：文件名建议 `日期_受试者ID_模式_标签.csv`，统一放入实验数据文件夹

## 六、常见问题

| 问题 | 解决 |
|:---|:-----|
| 双击 bat 后窗口一闪而过 | 终端窗口显示错误信息，截图发群里；多半是 Python 未装或依赖缺失 |
| 浏览器提示"无法访问此网站" | 终端窗口被关了，重新双击 bat |
| 摄像头画面黑屏 / 无画面 | 检查摄像头是否被其他软件占用；刷新页面重新允许权限 |
| 提示"未检测到人脸" | 光线不足或离摄像头太远，调整位置后稍等 1~2 秒 |
| 画面卡顿 | 右侧面板分辨率降到 640×480 |
| 模型加载失败 | GPU 不可用时程序会自动回退 CPU（稍慢但可用）；仍失败则重装依赖 |
