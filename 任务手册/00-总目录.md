## 🛠️ 关键概念速查

| 概念 | 含义 | 在本项目中的作用 | 详见手册 |
|------|------|------|:--:|
| **MediaPipe Face Mesh** | Google 的 468 点人脸关键点模型 | 所有人脸特征的输入源 | [[02-摄像头与FaceMesh人脸检测\|02]] |
| **EAR** | Eye Aspect Ratio，眼部长宽比 | 判断单帧眼睛开/闭 | [[03-特征提取：EAR眼部长宽比\|03]] |
| **MAR** | Mouth Aspect Ratio，嘴部长宽比 | 检测打哈欠 | [[04-特征提取：MAR嘴部长宽比\|04]] |
| **PERCLOS** | PERcentage of eye CLOSure | 时间窗口内闭眼比例，核心疲劳指标 | [[06-时间窗口统计：PERCLOS与疲劳追踪\|06]] |
| **solvePnP** | Perspective-n-Point，3D→2D 姿态求解 | 从 2D 关键点反推头部 3D 姿态 | [[05-特征提取：HeadPose头部姿态\|05]] |
| **状态机** | 有限状态自动机 (FSM) | 管理正常/风险/报警三级切换 | [[07-疲劳评分融合与状态机\|07]] |

## 📋 核心配置文件速查

所有可调参数集中在 `src/config.py`，你调参时只需改这一个文件：

```python
# ===== 眼部 =====
EAR_THRESHOLD = 0.22          # 多低算闭眼（越小越不敏感）
PERCLOS_WINDOW_SEC = 30       # 统计窗口（秒）
PERCLOS_THRESHOLD = 0.2       # 窗口内闭眼超过 20% 触发警告

# ===== 嘴部 =====
MAR_THRESHOLD = 0.6           # 多高算张嘴
MAR_YAWN_DURATION_SEC = 3.0   # 持续张嘴多久算哈欠

# ===== 头部 =====
PITCH_DOWN_THRESHOLD = 20     # 低头多少度触发
HEAD_DOWN_DURATION_SEC = 2.0  # 持续低头多久算异常

# ===== 评分 =====
EYE_CLOSED_05S_SCORE = 2      # 连续闭眼 > 0.5s
EYE_CLOSED_2S_SCORE = 4       # 连续闭眼 > 2s
PERCLOS_OVER_SCORE = 3        # PERCLOS 超阈值
YAWN_SCORE = 2                # 单次哈欠
YAWN_FREQ_SCORE = 3           # 1min 内哈欠 > 2 次
HEAD_DOWN_SCORE = 2           # 持续低头

# ===== 等级 =====
SCORE_NORMAL = 2              # 0-2: 正常
SCORE_RISK = 5                # 3-5: 风险（≥6: 报警）

# ===== 报警 =====
ALERT_COOLDOWN_SEC = 5.0      # 两次报警最小间隔（防骚扰）
```
