# 📷 阶段 1：摄像头与 Face Mesh 人脸检测

> **本阶段目标**：实时读取摄像头画面，用 MediaPipe 提取 468 个人脸关键点。
>
> ⏱️ 预计时长：30 分钟 | 💻 你负责运行 + 观察

---

## 🎓 你将学到什么

| 知识点 | 说明 |
|------|------|
| **OpenCV 摄像头读取** | `cv2.VideoCapture(0)` 打开摄像头，循环 `cap.read()` 取帧 |
| **BGR vs RGB** | OpenCV 用 BGR（蓝绿红），MediaPipe 要 RGB。要学会互相转换 |
| **MediaPipe Face Mesh** | Google 的预训练模型，输入一张脸，输出 468 个 3D 坐标点 |
| **归一化坐标** | MediaPipe 返回的 x,y 是 0~1 之间，要乘以图像宽高转为像素值 |
| **FPS 帧率** | 每秒处理多少帧。低于 10 就是"卡"，目标是 ≥ 15 |

### 补充知识：MediaPipe Face Mesh 是什么？

MediaPipe Face Mesh 是 Google 训练的一个深度学习模型，它不做"人脸识别"（不知道你是谁），只做**人脸关键点定位**——找到你脸上的 468 个特定位置。

这 468 个点覆盖了：
- 👁 眼部轮廓（上下眼睑、眼角）→ 用于 EAR
- 👄 嘴唇轮廓（上下唇、嘴角）→ 用于 MAR
- 👃 鼻子 → 用于 Head Pose
- 🧏 耳朵、眉毛、脸颊 → 辅助

```
         • • • • •  ← 眉毛
      •           •
    •   •     •   •   ← 眼睛（内外眼角 + 上下眼睑）
      •           •
         • • • • •
            •
         •     •      ← 鼻子
      •           •
    •               •  ← 嘴巴（嘴角 + 上下唇）
      •           •
         • • • • •
```

MediaPipe 的优势：
- **快**：CPU 就能跑到 20~30 FPS
- **准**：戴眼镜、侧脸、微表情都能跟踪
- **免费**：Apache 2.0 开源协议

## 🧪 你需要做什么

### 步骤 1：运行第一个实时检测程序

代码我已经写好，你只需：

```powershell
& "D:\Anaconda3\local\envs\yolo\python.exe" src/main.py
```

你会看到一个窗口，画面中你的脸被绿色网格覆盖——那就是 468 个关键点和它们之间的连线。

### 步骤 2：观察关键点

做以下动作，观察关键点是否稳定跟踪：

| 测试动作 | 观察什么 |
|------|------|
| 正面面对摄像头 | 绿网是否完整覆盖脸部 |
| 慢慢转头（左→右） | 绿网是否跟随，有没有跟丢？ |
| 慢慢低头/抬头 | 下巴和鼻子点是否还在？ |
| 戴眼镜（如果有） | 眼部关键点是否跳动？ |
| 用手挡住半张脸 | 绿网是否消失？恢复后能否重新检测？ |
| 离远/靠近摄像头 | 关键点是否始终在脸上？ |

### 步骤 3：记录 FPS

注意画面左上角显示的 FPS 数字：
- FPS ≥ 20：流畅 ✅
- FPS 10~20：凑合 ⚠
- FPS < 10：卡顿 ❌，告诉我你的电脑配置和分辨率

### 步骤 4：截图保存

截两张图保存到 `data/screenshots/`：
1. 正面正常检测的画面
2. 侧脸/低头的画面（标注哪些点偏离了）

截图会帮助我判断算法鲁棒性。

## 🔧 常见问题

| 问题 | 可能原因 | 解决 |
|------|------|------|
| 程序打不开 | Python 路径不对 | 确认用的是 yolo 环境的 python |
| 画面全黑 | 摄像头被其他程序占用 | 关掉 Zoom/微信/浏览器 |
| 检测不到人脸 | 光线太暗或太亮 | 调整光线，人脸正对摄像头 |
| 绿网抖动严重 | 光线不稳定或人脸太小 | 靠近摄像头，增加光照 |
| FPS 很低 | 分辨率太高 | 让我调低 `FRAME_WIDTH/HEIGHT` |
| 侧脸检测不到 | 偏转角度太大 | MediaPipe 在大约 60° 以内能跟踪 |
