# 👄 阶段 3：MAR 嘴部长宽比

> **本阶段目标**：理解 MAR 计算原理，标定自己的哈欠阈值，区分说话与哈欠。
>
> ⏱️ 预计时长：25 分钟 | 💻 你负责运行 + 标定阈值

---

## 🎓 你将学到什么

| 知识点 | 说明 |
|------|------|
| **MAR 公式** | Mouth Aspect Ratio，和 EAR 同样的思路，但用于嘴巴 |
| **哈欠 vs 说话** | 哈欠持续时间长（3~6s），说话张嘴短而频繁 |
| **持续时间的重要性** | 单帧 MAR 高不一定是哈欠，要持续一段时间 |

### 深入理解：MAR 公式

```
正常闭嘴:                    说话:                      打哈欠:
  ●──────────●               ●──────────●               ●──────────●
  │          │               │    ●●    │               │          │
  │  ──────  │               │   ●  ●   │               │          │
  │          │               │    ●●    │               │   ●  ●   │
  ●──────────●               ●──────────●               │   ●  ●   │
                                                         │          │
  MAR ≈ 0.1                   MAR ≈ 0.4                  ●──────────●
                                                          MAR ≈ 0.7+
```

**公式**：

$$
\text{MAR} = \frac{\|p_{上唇} - p_{下唇}\|}{\|p_{左嘴角} - p_{右嘴角}\|}
$$

**MediaPipe 关键点**：

| 位置 | 编号 | 
|------|:--:|
| 上唇中点 | 13 |
| 下唇中点 | 14 |
| 左嘴角 | 61 |
| 右嘴角 | 291 |

> 可选增强（DrowSAFE 做法）：增加辅助距离 N2(39,181), N3(269,405)，用三组垂直距离平均提升鲁棒性。

**哈欠的典型特征**：
- MAR 从 0.1~0.3 突然升到 0.6~0.9
- 持续时间 3~6 秒
- 通常伴随头部后仰（pitch 变小）

### 步骤 3：确定阈值

```
正常闭嘴 MAR:      ____ ∼ ____
说话时 MAR 峰值:   ____
大笑 MAR 峰值:     ____
哈欠 MAR:          ____ ∼ ____

建议哈欠阈值:      ____
建议持续时间:      3 秒（默认，如果说话容易被误判可调大到 4~5 秒）
```

**阈值设定原则**：
- MAR 阈值应该**高于**你说话时的最大值（避免把说话当哈欠）
- 同时**低于**你打哈欠时的最小值（确保检出哈欠）
- 配合持续时间过滤，双重保险

> 示例：说话最高 0.55，大笑 0.65，哈欠 0.70~0.90 → 阈值设为 **0.60**，持续时间 3s

### 步骤 4：验证

改 `config.py` 中的 `MAR_THRESHOLD`：
- 正常聊天 1 分钟 → 应该**不触发**哈欠
- 打一两个哈欠 → 应该**触发**哈欠计数

## 🔧 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 说话总被误判哈欠 | 阈值太低 | 调高阈值到 0.65+ |
| 微笑触发哈欠 | 微笑时嘴角拉开、MAR 反而变小，一般不会 | 如果遇到，加入持续时间限制 |
| 打哈欠没检测到 | 阈值太高 | 降低到 0.55 |
| 张嘴吃东西被误判 | MAR 高但不持续 3s | 增加最小持续时间 |
