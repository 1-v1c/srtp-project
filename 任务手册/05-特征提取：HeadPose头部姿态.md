>
> ⏱️ 预计时长：35 分钟 | 💻 你负责运行 + 验证角度方向

---

## 🎓 你将学到什么

| 知识点 | 说明 |
|------|------|
| **3D 姿态估计** | 如何从一张 2D 图片反推出物体在 3D 空间中的旋转角度 |
| **solvePnP** | Perspective-n-Point：给定 3D 坐标和对应的 2D 投影点，求解相机与物体的位置关系 |
| **欧拉角** | Pitch（俯仰）、Yaw（偏航）、Roll（翻滚）——飞机的三轴 |
| **相机内参** | 焦距、主点——描述相机光学特性的矩阵 |

### 深入理解：从 2D 脸到 3D 姿态

这其实是高中数学的延伸：

1. 我们知道一张"标准人脸"的 3D 形状（预设的参考坐标）
2. 摄像头拍到的是这张脸在 2D 平面上的投影
3. **solvePnP 就是反推**：要把这个标准 3D 脸旋转多少度、移动多少距离，才能投影成画面中你看到的样子？

```
     标准 3D 人脸模型              摄像头拍到的 2D 图像
     (鼻尖, 眼角, 嘴角...)    →    (像素坐标上的这些点)
     
              ↓ solvePnP 反推 ↓
              
     Pitch: 15°  (你在低头)
     Yaw:   -5°  (你微微右转)
     Roll:  2°   (你基本没歪头)
```

### 三个角度图解

```
Pitch (俯仰)          Yaw (偏航)           Roll (翻滚)
       ↑                    ←  →                 ↙  ↘
   低头为正              左转为正            左歪为正
       
   👤                   👤 →                  👤
    ↓                                        ↙
   (低头看地)          (转头看旁边)          (歪头)
```

| 角度 | 疲劳中的表现 | 正常范围 | 疲劳范围 |
|------|------|:--:|:--:|
| **Pitch** | 频繁点头、持续低头 | -15° ~ +15° | > +20°（低头）或波动频繁 |
| **Yaw** | 长时间不看前方 | -20° ~ +20° | > ±30° 持续 |
| **Roll** | 歪头异常姿态 | -10° ~ +10° | > ±15° |

### 步骤 4：模拟疲劳低头

> 示例：你低头时 Pitch = 28°，阈值设为 28 × 0.8 ≈ 22°

## 🔧 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 角度方向反了 | 3D 参考点坐标系与 solvePnP 输出约定不同 | 告诉我，加个负号就好 |
| 角度抖动很大 | 关键点检测不稳定 | 稍远离摄像头，减少头部快速移动 |
| 微低头就被判异常 | 阈值太低 | 调高 `PITCH_DOWN_THRESHOLD` |
| 角度数值不连续跳动 | 欧拉角的万向节死锁（gimbal lock） | 正常现象，90° 附近会跳 |
