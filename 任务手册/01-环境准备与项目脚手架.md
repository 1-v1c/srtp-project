打开终端（PowerShell），逐条执行：


### 步骤 2：理解 config.py

我不需要你做什么，但**请花 3 分钟读一遍 `config.py`**。它是你后续所有"调参"操作的唯一入口。

关键概念：
- **阈值类参数**（如 `EAR_THRESHOLD = 0.22`）：低于这个值就认为是"闭眼"。数字越小，越不敏感。
- **时长类参数**（如 `MAR_YAWN_DURATION_SEC = 3.0`）：状态持续多久才触发。
- **评分类参数**（如 `EYE_CLOSED_2S_SCORE = 4`）：满足某条件时加几分。

> 💡 **你的核心工作就是调整 config.py 里这些数字**，让系统既不过于敏感（频繁误报），也不过于迟钝（漏报）。

### 步骤 3：检查摄像头

```powershell
& "D:\Anaconda3\local\envs\yolo\python.exe" -c "
import cv2
cap = cv2.VideoCapture(0)
ret, frame = cap.read()
if ret:
    print(f'摄像头正常, 分辨率: {frame.shape[1]}x{frame.shape[0]}')
else:
    print('⚠ 摄像头打不开, 请检查')
cap.release()
"
```

## 🔧 常见问题

| 问题 | 解决方案 |
|------|------|
| `ModuleNotFoundError: No module named 'mediapipe'` | 之前安装过但又丢了，让我知道，我帮你重装 |
| 摄像头打不开 | 检查是否有其他程序（Zoom、微信视频）占用了摄像头 |
| 摄像头 ID 不对 | 默认用 `0`，如果有多个摄像头可能需要改为 `1`，告诉我 |
