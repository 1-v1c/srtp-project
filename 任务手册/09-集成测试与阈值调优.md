>
> ⏱️ 预计时长：60~120 分钟 | 💻 **你主导**，我辅助

---

## 🎓 你将学到什么

| 知识点 | 说明 |
|------|------|
| **端到端测试** | 不只看单个模块，而是跑完整流程，模拟真实场景 |
| **误报率 (FPR)** | 正常状态被错误判为疲劳的比例——越低越好 |
| **漏报率 (FNR)** | 疲劳状态没有被检出的比例——越低越好 |
| **阈值调优策略** | 如何系统地调整参数，而不是瞎试 |
| **ROC 思维** | 误报和漏报是 trade-off，降低一个会升高另一个 |

### 深入理解：误报 vs 漏报的权衡

```
          实际正常              实际疲劳
判为正常   ✅ 正确 (TN)          ❌ 漏报 (FN)  ← 危险！
判为疲劳   ❌ 误报 (FP) 烦人      ✅ 正确 (TP)

误报率 = FP / (FP+TN)    漏报率 = FN / (FN+TP)
```

**对司机来说**：
- 误报太多 → 烦，关掉系统 → 失去保护
- 漏报 → 真疲劳没检出 → 可能出事故

**你的任务**：在两者之间找到最佳平衡点。

### 科学的调参方法：控制变量法

```
❌ 错误做法：一次改 5 个参数 → "好像好一点了？" → 不知道哪个改对了
✅ 正确做法：一次只改 1 个 → 测试 → 记录效果 → 再改下一个
```

## 🧪 测试流程

### 测试 A：正常驾驶（验证误报率）

**操作**：
1. 像正常开车一样面对摄像头 **5 分钟**
2. 自然眨眼、偶尔看左右"后视镜"、偶尔低头看"仪表盘"
3. 不要故意做疲劳动作

**记录**：

| 指标 | 数值 |
|------|:--:|
| 测试时长 | 5 min |
| 误报次数（错误触发 RISK/ALERT） | `____` |
| 最高疲劳分数 | `____` |
| 平均疲劳分数 | `____` |
| 可接受吗？ | 是 / 否 |

**判断标准**：5 分钟内误报 ≤ 1 次 → 可接受。超过则需要调高阈值。

---

### 测试 B：模拟疲劳（验证漏报率）

**操作**：
1. **3 分钟**内，每隔约 30 秒做一次疲劳动作：
   - 第 1 次：闭眼 3 秒
   - 第 2 次：打一个哈欠 + 闭眼
   - 第 3 次：持续低头 3 秒
   - 第 4 次：闭眼 2 秒 + 低头 2 秒
   - 第 5 次：闭眼 4 秒（模拟微睡眠）

**记录**：

| 动作 | 应该触发什么 | 实际触发了什么 | 正确？ |
|------|------|------|:--:|
| 闭眼 3s | RISK | `____` | |
| 哈欠+闭眼 | ALERT | `____` | |
| 低头 3s | RISK | `____` | |
| 闭眼2s+低头2s | ALERT | `____` | |
| 闭眼 4s | ALERT | `____` | |
| **漏报次数** | | `____` | |
| **整体检出率** | | `____%` | |

**判断标准**：检出率 ≥ 80%（5 个动作至少检出 4 个）。

---

### 测试 C：边界情况

| 场景 | 操作 | 预期 | 实际 |
|------|------|------|:--:|
| 无人脸 | 离开摄像头 10s | 不崩溃、不误报 | |
| 重新出现 | 回来坐下 | 3s 内重新检测 | |
| 侧脸 45° | 持续看侧面 5s | 不误报、不崩溃 | |
| 戴/摘眼镜 | 操作 2 次 | 无缝切换 | |
| 光线变化 | 开关台灯 | 检测不中断 | |

## 📊 调参指南

### 如果误报太多（正常状态老报警）→ 提高阈值

| 症状 | 调的参数 | 方向 |
|------|------|:--:|
| 正常眨眼被判闭眼 | `EAR_THRESHOLD` | ↓ 降低（更不敏感） |
| 说话被判哈欠 | `MAR_THRESHOLD` | ↑ 提高 |
| 正常低头看仪表被判异常 | `PITCH_DOWN_THRESHOLD` | ↑ 提高 |
| PERCLOS 正常就高 | `PERCLOS_THRESHOLD` | ↑ 提高 |
| 动不动就 RISK | `SCORE_RISK` | ↑ 提高门槛 |
| 报警太频繁 | `ALERT_COOLDOWN_SEC` | ↑ 增大冷却 |

### 如果漏报太多（真疲劳没检出）→ 降低阈值

| 症状 | 调的参数 | 方向 |
|------|------|:--:|
| 真闭眼没检出 | `EAR_THRESHOLD` | ↑ 提高（更敏感） |
| 打哈欠没检出 | `MAR_THRESHOLD` | ↓ 降低 |
| 低头没检出 | `PITCH_DOWN_THRESHOLD` | ↓ 降低 |
| 闭眼 3s 还不到 ALERT | 各项 `_SCORE` | ↑ 加大分值 |
| 哈欠要很夸张才触发 | `MAR_YAWN_DURATION_SEC` | ↓ 减少要求 |

### 调参记录模板

每次改参数都要记录，方便回溯：

```

  用户感受: ____

```
