## 🎓 你将学到什么

| 知识点 | 说明 |
|------|------|
| **EAR 公式** | Eye Aspect Ratio，用 6 个关键点算眼睛的"扁的程度" |
| **阈值标定** | 为什么 0.22 是"闭眼"？你需要验证这个值对你是否合适 |
| **个体差异** | 有人天生眼睛小，有人单眼皮——阈值不能一刀切 |

### 深入理解：EAR 公式推导

EAR 是 2016 年 Soukupová 和 Čech 提出的方法。核心思想很简单：

**眼睛睁开时**：眼睛接近椭圆形 → 高度 / 宽度 ≈ 正常值（0.3~0.4）  
**眼睛闭合时**：眼睛变成一条缝 → 高度 / 宽度 ≈ 很小（< 0.2）

```
睁开时：                      闭合时：
  p1 ●──────────● p4           p1 ●──────────● p4
     │          │                  │··········│
  p2 ●    ● p3               p2 ●····● p3
     │          │                  │··········│
  p5 ●──────────● p6           p5 ●──────────● p6

EAR ≈ 0.35                     EAR ≈ 0.10
```

**公式**：

$$
\text{EAR} = \frac{\|p_2 - p_6\| + \|p_3 - p_5\|}{2 \cdot \|p_1 - p_4\|}
$$

- 分子：两组垂直距离之和（眼睑间距）
- 分母：2 倍水平距离（眼角间距）
- 眼睛闭合时分子变小，EAR 下降

**MediaPipe 中使用的 6 个点**：

| 位置 | 左眼编号 | 右眼编号 |
|------|:--:|:--:|
| 左眼角 p1 | 33 | 362 |
| 上眼睑外 p2 | 160 | 385 |
| 上眼睑内 p3 | 158 | 387 |
| 右眼角 p4 | 133 | 263 |
| 下眼睑内 p5 | 153 | 373 |
| 下眼睑外 p6 | 144 | 380 |

## 🧪 你需要做什么

### 步骤 1：运行 EAR 可视化程序

```powershell
& "D:\Anaconda3\local\envs\yolo\python.exe" src/main.py
```

画面左上角会显示左右眼的 EAR 值和平均值。

### 步骤 2：标定你的 EAR 阈值 —— 核心任务！

这是本阶段**最重要的工作**。做以下动作，每次记录 EAR 平均值：

| 动作 | 持续 | 记录 EAR |
|------|:--:|:--:|
| 🟢 正常睁眼（正面看屏幕） | 5s | `____` |
| 🟢 正常睁眼（微侧脸） | 5s | `____` |
| 🟡 眯眼（像看远处那样） | 5s | `____` |
| 🔴 完全闭眼 | 5s | `____` |
| 🔴 快速眨眼 10 次 | 10s | 最低值 `____` |

> 💡 记录至少 3 组数据取平均，减少偶然误差。

### 步骤 3：确定你的阈值

在表格里标出：

```
我的睁眼 EAR 范围:     ____  ∼  ____
我的闭眼 EAR 范围:     ____  ∼  ____
建议闭眼阈值（取中间值）:  ____
```

**阈值设定原则**：
- 阈值应**高于**你闭眼时的最大值（确保能检出闭眼）
- 阈值应**低于**你正常睁眼时的最小值（避免误判）
- 取两个范围的中间偏下值

> 示例：睁眼 0.28~0.38，闭眼 0.08~0.16 → 阈值设为 **0.20**

### 步骤 4：验证阈值

把 `config.py` 中的 `EAR_THRESHOLD` 改成你标定的值，重新运行。

- 正常看屏幕 30s → 画面上的 EAR 应该始终显示**绿色**
- 闭眼 2s → EAR 应该变成**红色**（低于阈值）

## 🔧 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| EAR 值抖动很大 | 人脸检测不稳定 | 稍远离摄像头，确保光照均匀 |
| 戴眼镜时 EAR 偏低 | 眼镜框遮挡眼睑 | 阈值适当调低 0.02 |
| 眯眼被误判为闭眼 | 阈值设太高了 | 降低阈值 |
| 快速眨眼时 EAR 短暂变红 | 正常现象 | 后续用"连续闭眼帧数"来过滤 |
