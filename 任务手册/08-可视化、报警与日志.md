## 🧪 你需要做什么

### 步骤 1：检查 UI 清晰度

- [ ] 所有数字清晰可读（字体大小合适？和背景对比度够？）
- [ ] 颜色变化即时（EAR 低于阈值立马变红）
- [ ] 状态条随等级变化颜色（绿→黄→红）
- [ ] ALERT 时边框闪烁明显

### 步骤 2：测试报警声音

- 故意触发 ALERT（闭眼 + 低头持续几秒）
- [ ] 听到报警音了吗？
- [ ] 音量是否合适？（太大/太小）
- [ ] 报警后冷却期内不会再响？
- [ ] 恢复正常后报警停止？

### 步骤 3：检查 CSV 日志

程序运行后，在项目目录下找到 `logs/fatigue_log_日期.csv`，用 Excel 打开：

- [ ] 文件存在且能正常打开
- [ ] 包含列：timestamp, ear, mar, pitch, yaw, roll, perclos, score, level, event
- [ ] 每一行对应什么事件？（正常帧/哈欠/报警？）
- [ ] 数据密度合理（每秒 15~30 行）

用 Excel 画一个简单的 PERCLOS 随时间变化折线图，看能看出什么规律。

### 步骤 4：提 UI 改进建议

这是**你的设计领域**。告诉我：

- 哪些信息显示位置不合理？
- 还需要显示什么信息？
- 颜色方案是否有更好的选择？
- 报警方式偏好？(声音/弹窗/屏幕闪烁)

## 🔧 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 画面文字太小 | 分辨率高 | 让我调大字号 |
| 中文乱码 | OpenCV 默认不支持中文 | 换英文或换绘图方式 |
| 日志文件为空 | 程序没正常关闭 | 确认按 `q` 退出而非直接关窗口 |
| 报警音不响 | Windows 权限或声音设备问题 | 检查系统音量 |
