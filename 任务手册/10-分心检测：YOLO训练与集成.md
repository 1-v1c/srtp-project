# 10-分心检测：YOLO 训练与集成

> 基于文献决策 #5：**YOLO 不做疲劳主线，作为分心检测的扩展功能**（YOLO 核心优势在检测而非精细关键点，疲劳走 MediaPipe 规则法路线）。
> 本文档为任务分析与规划，动工前先读本手册。

---

## 一、任务定义：两条技术路线

| | 路线 A：动作分类（推荐起步） | 路线 B：物件检测（二期增强） |
|:---|:---|:---|
| 做什么 | 整张图分类"正在做什么"（发短信/打电话/喝水…） | 检测"分心物件在哪"（手机/水杯/食物…） |
| 模型 | YOLO-cls（分类头） | YOLO-detect（检测头） |
| 数据 | State Farm 现成 22,424 张（10 类标注） | 需自定义标注，或裸用 COCO 预训练 |
| 输出 | 分心类别 + 置信度 | 物件框 + 类别 |
| 难度 | 极低 | 中 |

**决策：以路线 A 起步**，路线 B 作为二期增强（先零成本跑 COCO 预训练看效果，不佳再微调）。

### State Farm 10 类

```
c0 安全驾驶 / c1 右手发短信 / c2 右手打电话 / c3 左手发短信 / c4 左手打电话
c5 操作收音机 / c6 喝水 / c7 伸手拿东西 / c8 整理头发化妆 / c9 与乘客交谈
```

---

## 二、数据方案

### 公开数据集：State Farm Distracted Driver Detection

| 属性 | 数值 |
|:---|:---|
| 训练集 | 22,424 张（640×480 RGB，驾驶室视角） |
| 类别分布 | 10 类 × ~2,000~2,500 张（均衡） |
| 已知短板 | ⚠️ 仅白天图像；手部遮挡物件时检测难 |
| 获取 | Kaggle 竞赛页（免费，需账号） |

### 增强策略

- 自定义补采 **500~1000 张**（自己摄像头视角、不同光照），做微调
- 数据增强注意：**水平翻转会让左右手类别互换**（c1↔c3、c2↔c4），谨慎使用

---

## 三、训练流程（Ultralytics）

```
① 环境    pip install ultralytics
② 数据    下载 State Farm → YOLO 分类格式：
          dataset/train/c0/xxx.jpg ... / dataset/val/c0/xxx.jpg ...
③ 训练    yolo classify train data=dataset model=yolo11n-cls.pt epochs=50 imgsz=224
④ 评估    yolo classify val → accuracy / 混淆矩阵 / 各类 PR
⑤ 导出    model.export(format="onnx")
⑥ 集成    distraction.py：每帧推理 → 分心类别 + 置信度，与 main.py 并行
```

**模型选型**：YOLO11n（稳定生产推荐）或 YOLO26n（最新 NMS-free）；nano 档 2.4M 参数 / ~2.8MB，CPU 可实时。

---

## 四、成本估算（实证支撑）

| 案例 | 配置 | 结果 |
|:---|:---|:---|
| HuggingFace 公开模型 | YOLOv8n-cls 12 epochs | **训练 16 分钟**，验证精度 99.6% |
| P-YOLOv8 论文（2024） | YOLOv8n-cls @ RTX-A4000 | 99.46% 精度，2.84MB 模型 |

- **数据**：0 成本（公开）+ 自定义补采几百张
- **算力**：消费级 GPU 16 分钟；无 GPU 可用 Colab/Kaggle 免费 GPU
- **时间**：数据整理 1~2 天 + 训练半天 + 集成 2~3 天 ≈ **1 周出可用模型**

---

## 五、集成设计（与现有系统不冲突）

```
MediaPipe 管线（main.py）: 疲劳等级 L0~L3   ──┐
                                              ├─→ AEB 决策（疲劳 + 分心双输入）
YOLO 管线（distraction.py）: 分心类别+置信度  ──┘
```

- 两条管线完全独立（不同模型、独立进程/线程）
- **分心等级可作为 AEB"驾驶员意图一致性"输入的可信度辅助**（分心中 → 驾驶员意图不可靠 → 算法加大接管权重）
- 性能：同帧跑 FaceMesh + YOLO11n，CPU 约 ~70ms/帧（14 FPS）；有 GPU 无压力

## 六、实施计划

| 阶段 | 内容 | 预计 |
|:---:|:---|:---:|
| 1 | YOLO11n-cls + State Farm 训练 → 验证 → 导出 ONNX | 1 周 |
| 2 | 集成 distraction.py（独立管线 + 分心等级输出） | 2~3 天 |
| 3 | 自定义补采微调（覆盖自己摄像头视角） | 1~2 天 |
| 4 | 与疲劳管线联合测试 + 分心等级接入 AEB | 2~3 天 |

---

## 七、风险与注意

1. 同数据集内验证精度偏高（99%+），真实场景会掉点——以自定义数据实测为准
2. State Farm 只有白天 → 补采需覆盖不同光照
3. 手部遮挡物件是检测难点 → 分类路线受影响小，检测路线需专门补数据
4. 左右手类别镜像问题（见数据增强）
