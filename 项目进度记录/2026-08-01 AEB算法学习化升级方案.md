# AEB 学习化升级方案（模仿学习 / 强化学习）

> 把规则式 AEB 决策升级为学习模型（结合疲劳检测），评估 IL / RL 路线的投入与产出。

---

## 一、任务定性（决定一切估算）

**低维策略学习，不是端到端视觉驾驶**：输入 8 维数值（疲劳等级/车速/障碍物速度/加速度/双方向角/相对距离/意图一致性）→ 输出 3 维动作（制动等级/权重/加速度）。

对比端到端驾驶（PilotNet 72 小时数据、ONE-Drive 3 万小时 / 512 张 A100），本任务数据与算力需求小 3~4 个数量级。

**最大杠杆**：队友的规则式 AEB 算法 = 现成专家，可**自动生成训练数据**，零人工采集成本。

---

## 二、三条路线对比

| 维度 | BC（行为克隆） | 离线 RL（CQL 为代表） | 在线 RL |
|:---|:---|:---|:---|
| 学习方式 | 抄专家作业（监督学习） | 静态数据学 Q 函数 | 环境交互试错 |
| 数据需求 | 5万~20万条离线样本 | 同左（复用） | 数百万次交互（10~50 倍） |
| 算力 | 单张消费级 GPU，1~3 小时 | 与 BC 同量级（无在线交互） | BC 的 10~100 倍 |
| 效果上限 | ≤ 专家水平 | 接近/略超专家，**鲁棒性好** | 可超专家，但贵且难调 |
| 长时序鲁棒性 | 差（分布偏移累积） | 好（Waymo 实证：碰撞率比最强 BC 低 7 倍） | 好 |
| 对 AEB 秒级任务 | 差距被压缩，但方向不变 | 推荐 | 周期内不值得 |
| 学习成本 | 低 | 算法复杂一点（~100 行） | 高（奖励设计 + 探索调参） |

---

## 三、概念速记

| 概念 | 一句话 |
|:---|:---|
| **BC** | 行为克隆：让模型"抄作业"，状态→动作监督学习 |
| **分布偏移** | BC 的毛病：模型只见过专家走的路，自己走就偏离，越偏越错 |
| **DAgger** | 治分布偏移：模型边跑边问专家，把自己遇到的状态+专家答案补进数据集，迭代重训 |
| **CQL** | 离线 RL：用静态数据学 Q 函数（有长期后果概念）+ 主动压低未知动作估值（保守）→ 便宜 + 鲁棒 + 不作死 |

---

## 四、推荐路线（三阶段）

```
阶段 1（4~6 周）: BC 快速验证
  规则专家生成数据 → BC 训练 → 闭环测试（颜色网格指标）
  产出：可工作的基线模型

阶段 2（追加 2~3 周）: 离线 RL（CQL）——最优解
  复用同一批数据 → CQL 训练 → 闭环测试
  产出：鲁棒性显著提升的模型（零新增数据/算力成本）

阶段 3（可选，有 CARLA 后）: 在线 RL 微调
  让策略超过规则专家 → 对 SRTP 周期大概率不值得，列为展望
```

---

## 五、底线与风险

1. **规则兜底永不可少**：`TTC < 0.8s 强制最大制动`——学习模型只做分级/权重调制，安全关键系统不能纯学习
2. **数据多样性**：疲劳等级 L0~L3 × 场景 × 意图模式全覆盖，否则对应输入是分布外
3. **长尾重采样**：紧急场景在训练集中占比提到 30~50%（否则模型学到的全是"不制动"）
4. **CQL 前提**：专家数据质量好、覆盖广；否则"保守"退化为"胆小"

---

## 六、结论速记

- 数据：**5万~20万条，规则专家自动生成**（零人工）
- 算力：**单张消费级 GPU，训练 1~3 小时**
- 时间：**BC 4~6 周 → CQL 追加 2~3 周**
- 路线：BC 打底 → **CQL 提升**（性价比最高）→ 在线 RL 留作展望
- 依据：Waymo 2025 实证（arXiv:2508.07029）、ONE-Drive 2024（arXiv:2412.02689）、Robust BC 2021
