### 🛠 工具产出

#### CalibTool — 特征标定采集器 `[[calibtool.py]]`

为 EAR/MAR/HeadPose 全流程标定打造的专用工具，替代手动盯屏记录：

| 功能 | 说明 |
|------|------|
| 🖱 鼠标操作 | 点击切换阶段（EAR/MAR/HEAD）、选择标签 |
| ⏺ 录制采集 | 选中标签 → 点录制（或空格）→ 自动统计 min/max/avg |
| 📊 实时显示 | 顶栏第二行显示当前 EAR/MAR 数值 |
| 📋 侧面板 | 最近 7 条记录卡片，点击选中、Backspace 删除 |
| 📤 CSV 导出 | 录制时不写入文件（防污染），退出或点导出时批量写入 |
| 🎨 iOS 风格 UI | 圆角按钮、半透明面板、4 级排版层级、8px 网格对齐 |

**设计迭代记录**：
- 初版用 `cv2.putText` → 中文全部变 `?` → 改用 PIL + 微软雅黑渲染
- 按钮自称圆角但从未实现 → 新增 `_rounded_rect()` / `_rounded_outline()` 真正圆角
- 纯白文字 `#FFF` → off-white `#F0F0F0`（暗色背景下不刺眼）
- 录制按钮从标签行内移到右侧固定位：空闲灰底灰字、录制中红底白字
- MAR 标签重排：`闭嘴→微笑→说话→惊讶→大笑→哈欠`（张口程度渐进）
