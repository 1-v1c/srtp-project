### 2.2 原型编码实现（6/14）

围绕文献结论，按 `任务手册` 逐阶段推进：

#### 阶段 1-2：摄像头 + Face Mesh（手册 02）

| 文件 | 功能 |
|------|------|
| `camera.py` | 摄像头封装，镜像翻转，FPS 统计 |
| `detector.py` | MediaPipe Tasks API，468 点检测，绿网绘制 |
| `main.py` | 串联入口，`s` 截图，`q` 退出 |

**踩坑记录**：
- MediaPipe 0.10.35 废弃 `solutions` API → 迁移至 Tasks API
- MediaPipe C 库不支持中文路径 → 模型移至纯英文路径 `E:\ObsidianVault\fatigue_detection_models\`

**验证结果**：FPS ≈ 30，正面/侧面绿网不跟丢，截图 2 张验收通过。

#### 阶段 3：EAR 眼部长宽比（手册 03）

| 文件 | 新增内容 |
|------|----------|
| `features.py` | `calculate_ear()` + `EARSmoother`（5 帧滤波） |
| `main.py` | 左上角实时显示 EAR_L / EAR_R / EAR_avg |

**个人阈值标定**：

| 动作 | EAR Avg |
|------|:--:|
| 正常睁眼 | 0.400 |
| 眯眼 | 0.132 |
| 完全闭眼 | 0.094 |
| 快速眨眼（最低） | 0.125 |

**结论**：阈值 0.22 恰好居中，睁眼远高于、闭眼远低于，误判风险极低，无需调参。

#### 阶段 4：MAR 嘴部长宽比（手册 04）

| 改进 | 说明 |
|------|------|
| MAR 公式升级 | 1 组 → **3 组垂直测量取平均**，解决微笑/说话混叠 |
| 哈欠判定 | MAR > 0.65 + 持续 2.8s + 0.2s 宽容缓冲 |
| 视觉反馈 | 嘴部 8 个标记点 + 实时 MAR 数值 + Mouth 状态 |

**当前参数**：

| 参数 | 值 | 含义 |
|------|:--:|------|
| `EAR_THRESHOLD` | 0.22 | 闭眼判定阈值 |
| `MAR_THRESHOLD` | 0.65 | 张嘴判定阈值 |
| `MAR_YAWN_DURATION_SEC` | 2.8 | 哈欠持续时长 |
| `MAR_YAWN_GRACE_SEC` | 0.2 | 短暂闭合宽容缓冲 |

### 2.3 工具开发：CalibTool

针对手动盯屏记录不准、分心、峰值易漏的痛点，开发了专用标定采集器。

| 功能 | 操作方式 |
|------|----------|
| 阶段切换 | 鼠标点顶栏 `[EAR]` `[MAR]` `[HEAD]`，或按 `1` `2` `3` |
| 选择标签 | 鼠标点底栏按钮，或按 `Tab` 轮换 |
| 录制采集 | 点右侧 `⏺ 录制` 或按空格，自动统计 min/max/avg |
| 实时数据 | 顶栏第二行显示当前 EAR / MAR 数值 |
| 记录管理 | 侧面板显示最近 7 条卡片，点击选中，Backspace 删除 |
| CSV 导出 | 录制时暂存内存（防污染），退出或点导出时批量写入 |

**UI 设计迭代**（3 轮）：
1. cv2 无法渲染中文 → PIL + 微软雅黑接管
2. 按钮自称圆角但未实现 → `_rounded_rect()` / `_rounded_outline()` 真正圆角
3. 纯白文字刺眼、排版无体系 → off-white 配色 + 4 级字号 + 8px 网格
